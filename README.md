# 住宅ローン借り換えシミュレーション

元利均等返済を前提に、毎月返済額・総支払額・諸費用の回収時期・残高推移を比較するWebアプリです。スマートフォンとPCに対応しています。

入力データはブラウザ内で計算され、外部に送信されません。金利は完済まで一定とし、ボーナス返済や住宅ローン控除は含めません。

## ローカルで起動

```sh
python -m http.server 8000
```

http://localhost:8000 を開きます。

mainブランチのルートを公開します。

## 銀行プリセット

公式サイト確認日: 2026-10-01。`banks.js` に西京銀行、中国ろうきん（会員）、JA山口県の金利、手数料、条件、出典を定義しています。リアルタイム取得は行いません。

範囲金利は下限・上限を選択でき、実際の見積金利に編集できます。定率手数料は費用の借入組み込みも含めて算出します。保証料等の未確定費用は見積入力が必須です。電子契約を前提とします。固定選択期間終了後は入力した想定金利で残高・残存期間から再計算します。

JAは公式キャンペーン資料と借換応援型概要に限度額・保証料の違いがあるため、適用条件は窓口確認が必要です。
